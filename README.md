# Sistema de Controle para Pequenos Comércios

> Este projeto foi desenvolvido especialmente para pequenos comércios que precisam de um sistema simples para controle de estoque. A ideia é oferecer uma solução básica, sem muitas funcionalidades desnecessárias.

O sistema foi desenvolvido utilizando **Python** e **MySQL**.

## Funcionalidades

O sistema possui as seguintes funcionalidades:

1. Cadastrar produtos
2. Vender produtos
3. Buscar produtos
4. Listar produtos
5. Adicionar estoque
6. Sair

## Tecnologias utilizadas

* **Python**
* **MySQL**

## Objetivo

O objetivo deste projeto é ajudar pequenos comerciantes que não precisam de sistemas grandes e complexos, oferecendo apenas as funções básicas necessárias para o controle de produtos e estoque.
